# The Agent's Uh-Oh

> Obviously

An agent that is completely lost does not admit it — it stalls with fake confidence instead. "Obviously" is the bluff: total certainty, followed by absolutely nothing. The word is the confession.

`main.ts` holds the word as a constant, validates it (1–99 characters, a single word with no whitespace and no control characters), then writes it to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`) with no trailing newline, and logs the character count.
